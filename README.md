About project:

"The Met";

The Met is the official website of the museum, where visitors can find all the latest information about exhibitions, opening hours, and upcoming events. It offers virtual tours that allow users to explore various exhibitions and galleries online, making art accessible regardless of location. Visitors can discover iconic masterpieces showcased at the museum and learn more about their history and cultural significance. Additionally, the website provides contact details and a feedback form, enabling direct communication with the museum administration. This platform serves as an informative, educational, and interactive space for art enthusiasts.

Getting Started:

- clone the repository:
  git clone https://github.com/Shevchuchka/layout_landing-page.git
  cd layout_landing-page

- install dependencies:
  npm install
  # or
  yarn install

- run the project locally:
  npm start
  # or
  yarn start

Features:
- Responsive design - optimized for different screen sizes and devices, responses on width 320px, 744px, 1260px
- Scroll to top button - easly return to the top of the page
- Animated effects - smooth transitions, guidance effects and interactive elements to improve UX.
- Simplified Mode - the focus on the main functions is the use of simplified shapes, large buttons, intuitive design.
Load reduction - content optimization for weak devices or rapid loading.
